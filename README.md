# Fresh Bloom

A premium, responsive static storefront for Fresh Bloom cosmetics in Pakistan. The site is designed for GitHub Pages and includes a polished home page, product catalog, filters, sorting, cart, wishlist, offers, policy templates, contact form, checkout placeholder, and responsive mobile navigation.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Deploy to GitHub Pages

1. Push to `main`.
2. In **Settings → Pages**, choose **GitHub Actions** as the source.
3. The included `.github/workflows/pages.yml` deploys the site automatically.

## Before launch

- Replace demo product data and sample review text in `script.js`.
- Replace Unsplash images with licensed Fresh Bloom product photography.
- Configure real business contact details, shipping charges, delivery times and policy text.
- Connect forms, authentication, orders and a trusted payment provider through a secure backend. This static demo never stores raw card details.
